calc_bias(countrates, sig, cvec, da=1e-07)[source]

Calculate the bias in the best-fit count rate from estimating the covariance matrix. This calculation is derived in the paper.

Parameters:

  • countrates (ndarray) – 1D array of shape (nrates,) of count rates at which the bias is desired.

  • sig (float) – Single read noise.

  • cvec (ndarray) – 1D array of shape (ndiffs,). Weight vector on resultant differences for initial estimation of count rate for the covariance matrix. Will be renormalized inside this function.

  • da (float, optional) – Fraction of the count rate plus sig**2 to use for finite difference estimate of the derivative. Default is 1e-7.

Returns:

bias (np.ndarray) – 1D array of shape (nrates,) of the bias of the best-fit count rate from using cvec plus the observed resultants to estimate the covariance matrix.

fill_masked_reads(diffs2use)[source]

Replace countrates, uncertainties, and chi squared values that are NaN because resultant differences were doubly omitted. For these cases, revert to the corresponding values in with fewer omitted resultant differences to get the correct values without double-coundint omissions.

Parameters:

diffs2use – A 2D array of shape (ndiffs, npix), matching self.countrate_oneomit in shape, with zero for resultant differences that were masked and one for differences that were not masked.

Notes

This function replaces the relevant entries of self.countrate_twoomit, self.chisq_twoomit, self.uncert_twoomit, self.countrate_oneomit, and self.chisq_oneomit in place. It does not return a value.

fit_ramps(diffs, Cov, sig, countrateguess=None, diffs2use=None, detect_jumps=False, resetval=0, resetsig=inf, rescale=True, dn_scale=10)[source]

Function fit_ramps. Fits ramps to read differences using the covariance matrix for the read differences as given by the diagonal elements and the off-diagonal elements.

Parameters:

  • diffs (ndarray) – 2D array of shape (ndiffs, npix) containing the resultant differences.

  • Cov (Covar) – Class holding the covariance matrix information.

  • sig (float | ndarray) – Read noise. A scalar or a 1D array of shape (npix,).

  • countrateguess (ndarray | None, optional) – 1D array of shape (npix,) of count rates to be used to estimate the covariance matrix. Default is None.

  • diffs2use (ndarray | None, optional) – 2D array of shape (ndiffs, npix); mask of whether to use each resultant difference for each pixel. Default is None.

  • detect_jumps (bool, optional) – Run the jump detection machinery. Default is False.

  • resetval (float | ndarray, optional) – Priors on the reset values. A scalar or a 1D array of shape (npix,). Default is 0.

  • resetsig (float | ndarray, optional) – Uncertainties on the reset values. A scalar or a 1D array of shape (npix,). Default is np.inf.

  • rescale (bool, optional) – Scale the covariance matrix internally. Default is True.

  • dn_scale (float, optional) – How often (in steps) to rescale the running determinant tallies. Default is 10.

Returns:

Ramp_Result – Class holding detailed ramp information.

mask_jumps(diffs, Cov, sig, threshold_oneomit=20.25, threshold_twoomit=23.8, diffs2use=None)[source]

Function mask_jumps implements a likelihood-based, iterative jump detection algorithm.

Parameters:

  • diffs (ndarray) – 2D array of shape (ndiffs, npix) containing the resultant differences.

  • Cov (Covar) – Class holding the covariance matrix information. Must be based on differences alone (without the pedestal).

  • sig (float | ndarray) – Read noise. A scalar or a 1D array of shape (npix,).

  • threshold_oneomit (float, optional) – Minimum chi-squared improvement to exclude a single resultant difference. Default is 20.25.

  • threshold_twoomit (float, optional) – Minimum chi-squared improvement to exclude two sequential resultant differences. Default is 23.8.

  • diffs2use (ndarray | None, optional) – 2D array of shape (ndiffs, npix) indicating which resultant differences are okay (1) or contaminated (0). Default is None.

Returns:

  • diffs2use (np.ndarray) – 2D array of shape (ndiffs, npix); mask of resultant differences after jump detection.

  • countrates (np.ndarray) – 1D array of shape (npix,) of count rates after masking pixels and resultants in diffs2use.
