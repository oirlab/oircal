acn_filter(cube, in_place=True, avg_type='pix', perint=False, edge_wrap=False, left_ref=True, right_ref=True, nleft=4, nright=4, mean_func=<function median>, **kwargs)[source]

Row-dependent differences between even and odd columns (i.e. ACN that changes with row, not just a constant offset per column). They are row-series describing how the even or odd reference pixels vary vs row (and frame), after baseline removal.

ACN correction using side reference columns. Separately estimates row-dependent even and odd column offsets, then subtracts them from the full image.

Parameters:

  • cube (ndarray) –

    Input data, either:

    • 2D array of shape (H, W), a single frame, or

    • 3D array of shape (N, H, W), a stack of frames.

  • in_place (bool, optional) – If False, the input array will be copied. Default is True.

  • avg_type (str, optional) –

    Baseline removal mode for reference pixels. One of:

    • ’pix’ : remove per-pixel mean over integration (best for many frames). Default.

    • ’frame’ : remove per-frame global mean of refs.

    • ’int’ : remove a single global mean over the whole ramp.

  • perint (bool, optional) – Passed to calc_col_smooth: smooth per integration instead of per frame. Default is False.

  • edge_wrap (bool, optional) – Passed to calc_col_smooth: mirror edges before smoothing to reduce ringing. Default is False.

  • left_ref (bool, optional) – Whether to use left and/or right side reference columns. Default is True.

  • right_ref (bool, optional) – Whether to use left and/or right side reference columns. Default is True.

  • nleft (int, optional) – Number of left/right reference columns to use. Default is 4.

  • nright (int, optional) – Number of left/right reference columns to use. Default is 4.

  • mean_func (Callable, optional) – Function to compute averages (e.g., np.median or robust.mean). Default is np.median.

  • **kwargs – Passed to calc_col_smooth.

Returns:

out (np.ndarray) – ACN-corrected array (same shape as input, float32).

acn_filter_nobaserm(cube, in_place=True, perint=False, edge_wrap=False, left_ref=True, right_ref=True, nleft=4, nright=4, mean_func=<function median>, **kwargs)[source]

ACN correction using side reference columns, without any baseline/mean removal.

This version uses the raw left/right reference pixel values (after top/bottom correction), averaged over reference columns, then smoothed vs. row, and subtracted from even/odd columns.

Parameters:

  • cube (ndarray) –

    Input data, either:

    • 2D array of shape (H, W), a single frame, or

    • 3D array of shape (N, H, W), a stack of frames.

  • in_place (bool, optional) – If False, the input array will be copied. Default is True.

  • perint (bool, optional) – Passed to calc_col_smooth: smooth per integration instead of per frame. Default is False.

  • edge_wrap (bool, optional) – Passed to calc_col_smooth: mirror edges before smoothing to reduce ringing. Default is False.

  • left_ref (bool, optional) – Whether to use left and/or right side reference columns. Default is True.

  • right_ref (bool, optional) – Whether to use left and/or right side reference columns. Default is True.

  • nleft (int, optional) – Number of left/right reference columns to use. Default is 4.

  • nright (int, optional) – Number of left/right reference columns to use. Default is 4.

  • mean_func (Callable, optional) – Function to combine multiple reference columns (e.g., np.median). NOTE: this function is not used for baseline subtraction here, only for averaging across columns. Default is np.median.

  • **kwargs – Passed to calc_col_smooth.

Returns:

out (np.ndarray) – ACN-corrected array (same shape as input, float32).

calc_avg_cols(refs_left=None, refs_right=None, avg_type='pix', mean_func=<function median>, **kwargs)[source]

Calculate average of column references Determine the average values for the column references, which is subsequently used to estimate the 1/f noise contribution.

Parameters:

  • refs_left (ndarray | None, optional) – 3D array of shape (nz, Nrows, nleft) of left reference columns. Default is None.

  • refs_right (ndarray | None, optional) – 3D array of shape (nz, Nrows, nright) of right reference columns. Default is None.

  • avg_type (str, optional) –

    Type of ref column averaging to perform to determine ref pixel variation. Allowed values are ‘pixel’, ‘frame’, or ‘int’.

    • ’pixel’ : For each ref pixel, subtract its avg value from all frames.

    • ’frame’ : For each frame, get avg ref pixel values and subtract framewise.

    • ’int’ : Calculate avg of all ref pixels within the ramp and subtract.

    Default is ‘pix’.

  • mean_func (Callable, optional) – Function to use to calculate averages of reference columns. Default is np.median.

  • **kwargs – Unused.

Same output as calc_avg_cols(), but does NOT remove reference pixel means / DC offsets.

  • refs_right (ndarray | None, optional) – 3D array of shape (N, H, nright) of the right reference strip. Default is None.

Returns:

refs_side_avg (np.ndarray) – 2D array of shape (N, H). Row-averaged reference drift without mean removal.

calc_col_smooth(refvals, data_shape, perint=False, edge_wrap=False, delt=0.000524, savgol=False, winsize=31, order=3, **kwargs)[source]

Perform optimal smoothing of side ref pix Generates smoothed version of column reference values. Smooths values from calc_avg_cols() via FFT.

Parameters:

  • refvals (ndarray) – 2D array of shape (nz, Nrows) of averaged column reference pixels.

  • data_shape (tuple) – Shape of original data (nz,Nrows,Ncols)

  • perint (bool, optional) – Smooth side reference pixel per int, otherwise per frame. Default is False.

  • edge_wrap (bool, optional) – Add a partial frames to the beginning and end of each averaged time series pixels in order to get rid of edge effects. Default is False.

  • delt (float, optional) – Time between reference pixel samples. Default is 5.24E-4.

  • savgol (bool, optional) – Using Savitsky-Golay filter method rather than FFT. Default is False.

  • winsize (int, optional) – Size of the window filter. Default is 31.

  • order (int, optional) – Order of the polynomial used to fit the samples. Default is 3.

  • **kwargs – Unused.

ref_filter(input_data, nchans=4, in_place=True, avg_type='pix', perint=False, edge_wrap=False, left_ref=True, right_ref=True, nleft=4, nright=4, **kwargs)[source]

Optimal Smoothing Performs an optimal filtering of the vertical reference pixel to reduce 1/f noise (horizontal stripes). FFT method adapted from M. Robberto IDL code: http://www.stsci.edu/~robberto/Main/Software/IDL4pipeline/

Parameters:

  • input_data (ndarray) – Input datacube, 2D of shape (Nrows, Ncols) or 3D of shape (nz, Nrows, Ncols).

  • nchans (int, optional) – Number of output amplifier channels in the detector. Default is 4.

  • in_place (bool, optional) – Perform calculations in place. Input array is overwritten. Default is True.

  • avg_type (str, optional) – Type of ref col averaging to perform. Allowed values are ‘pix’, ‘frame’, or ‘int’. Default is ‘pix’.

  • perint (bool, optional) – Smooth side reference pixel per integration, otherwise do frame-by-frame. Default is False.

  • edge_wrap (bool, optional) – Mirror edges before smoothing to reduce edge effects. Default is False.

  • left_ref (bool, optional) – Include left reference cols when correcting 1/f noise. Default is True.

  • right_ref (bool, optional) – Include right reference cols when correcting 1/f noise. Default is True.

  • nleft (int, optional) – Specify the number of left reference columns. Default is 4.

  • nright (int, optional) – Specify the number of right reference columns. Default is 4.

  • **kwargs – Passed to calc_avg_cols and calc_col_smooth, e.g. savgol (use a Savitsky-Golay filter rather than FFT), winsize (window size), order (polynomial order) and mean_func (averaging function).

Correct amplifier offsets Matches all amplifier outputs of the detector to a common level. This routine subtracts the average of the top and bottom reference rows for each amplifier and frame individually.

Parameters:

  • cube (ndarray) – Input datacube, 2D of shape (Nrows, Ncols) or 3D of shape (nz, Nrows, Ncols).

  • nchans (int, optional) – Number of output amplifier channels in the detector. Default is 4.

  • altcol (bool, optional) – Calculate separate reference values for even/odd columns. Default is False.

  • supermean (bool, optional) – Add back the overall mean of the reference pixels. Default is False.

  • in_place (bool, optional) – Perform calculations in place. Input array is overwritten. Default is True.

  • top_ref (bool, optional) – Include top reference rows when correcting channel offsets. Default is True.

  • bot_ref (bool, optional) – Include bottom reference rows when correcting channel offsets. Default is True.

  • ntop (int, optional) – Specify the number of top reference rows. Default is 4.

  • nbot (int, optional) – Specify the number of bottom reference rows. Default is 4.

  • **kwargs – Passed to the averaging function, e.g. mean_func (callable used to calculate averages).

smooth_fft(data, delt, first_deriv=False, second_deriv=False)[source]

Optimal smoothing algorithm Smoothing algorithm to perform optimal filtering of the vertical reference pixel to reduce 1/f noise (horizontal stripes), based on the Kosarev & Pantos algorithm. This assumes that the data to be filtered/smoothed has been sampled evenly. If first_deriv is set, then returns two results if second_deriv is set, then returns three results. Adapted from M. Robberto IDL code: http://www.stsci.edu/~robberto/Main/Software/IDL4pipeline/

Parameters:

  • data (ndarray) – 1D array of shape (nsamples,) of the signal to be filtered.

  • delt (float) – Delta time between samples.

  • first_deriv (bool, optional) – Return the first derivative. Default is False.

  • second_deriv (bool, optional) – Return the second derivative (along with first). Default is False.
