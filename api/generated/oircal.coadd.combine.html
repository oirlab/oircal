oircal.coadd.combine

oircal.coadd.combine

combine(input_data, input_err=None, mask=None, method='wmean', err_method='se', do_sigma_clip=False, sigma_thresh_low=5.0, sigma_thresh_high=5.0, min_keep=3, max_cores=1)[source]

Combine a stack of measurements along its first axis.

The stack can be e.g. frames of shape (Nframes, Nrows, Ncols), or measurements such as RVs of shape (Nobs,) or (Nobs, Norders). Each 1D slice along the first axis is combined independently, using its good values: those with mask True, finite data and (if input_err is given) finite errors, optionally sigma clipped. With N good values:

method sets the combined value:

  • ‘wmean’: inverse-variance weighted mean, with weights w = 1 / input_err**2.

  • ‘mean’: mean.

  • ‘median’: median.

err_method sets its uncertainty:

  • ‘se’: standard error propagated from input_err. For ‘wmean’ it is 1 / sqrt(sum(w)); for ‘mean’ it is sqrt(sum(input_err**2)) / N; for ‘median’ it is that of the mean times sqrt(pi / 2), the large-N ratio for Gaussian data. None if input_err is not given.

  • ‘scatter’: measured from the spread of the good values. For ‘wmean’ it is sqrt(sum(w * (x - wmean)**2) / ((N - 1) * sum(w))); for ‘mean’ it is the sample standard deviation (ddof=1) / sqrt(N); for ‘median’ it is that of the mean times sqrt(pi / 2). With N = 1 the value’s own input_err is used, or NaN without input_err.

With a single good value, it is used as is. With none, the value and error are NaN.

Parameters:

  • input_data (ndarray) – Array of shape (N, …) of measurements.

  • input_err (ndarray | None, optional) – Array of the same shape as input_data of uncertainties. Required for method ‘wmean’ and for err_method ‘se’. Default is None.

  • mask (ndarray | None, optional) – Boolean array of the same shape as input_data where True is good. Not modified. If None, all finite values are good. Default is None.

  • method (str, optional) – How to combine the good values: ‘wmean’, ‘mean’ or ‘median’. Default is ‘wmean’.

  • err_method (str, optional) – How to compute the uncertainty: ‘se’ (propagated standard error) or ‘scatter’ (measured from the spread of the good values). Default is ‘se’.

  • do_sigma_clip (bool, optional) – Sigma clip each slice’s good values before combining, using the biweight location and midvariance (see sigma_clip_stack()). Only done if N is more than 3. Default is False.

  • sigma_thresh_low (float | None, optional) – Low-side sigma clipping threshold in standard deviations. If None, no low-side clipping. Default is 5.0.

  • sigma_thresh_high (float | None, optional) – High-side sigma clipping threshold in standard deviations. If None, no high-side clipping. Default is 5.0.

  • min_keep (int | float, optional) – Minimum number of good values to keep per slice when sigma clipping. A value below 1 is a fraction of N. Default is 3.

  • max_cores (int, optional) – Maximum number of CPU cores to use. Default is 1.

Returns:

  • data (np.ndarray) – Array of shape input_data.shape[1:] of combined values (0-dimensional for 1D input).

  • err (np.ndarray or None) – Array of the same shape as data of uncertainties. None for err_method ‘se’ without input_err.

  • mask (np.ndarray) – Boolean array of the same shape as input_data of the values used (True), after sigma clipping. Use it to combine other quantities over the same values.
