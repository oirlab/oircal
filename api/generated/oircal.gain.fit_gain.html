fit_gain_and_readnoise(times, input_data, ...)

Fit the detector gain and/or read noise from a set of up-the-ramp exposures.
fit_gain_and_readnoise(times, input_data, init_gain, init_rn, input_dq_raw=None, dq_flags=None, fit_gain=True, fit_rn=True, method='quad', delta_gains=None, delta_rns=None, countratesidentical=False, mode='per_pixel', max_cores=1)[source]

Fit the detector gain and/or read noise from a set of up-the-ramp exposures.

Maximizes the likelihood of the ramps, marginalized over each ramp’s count rate, as a function of gain and read noise (Brandt 2025, PASP, 137, 125006). Either parameter can be held at its initial value: fit the read noise alone from darks (fit_gain=False), or the gain alone with a known read noise (fit_rn=False). Read differences touching a read flagged DO_NOT_USE or SATURATED, or ending on a read flagged JUMP_DET, are left out.

Parameters:

  • times – 1D array of shape (Nreads,) of the read times (s).

  • input_data – 4D array of shape (Nfiles, Nreads, Nrows, Ncols) of ramps (DN).

  • init_gain – Initial gain (e-/DN), a float or a 2D array of shape (Nrows, Ncols). Fixed if fit_gain is False.

  • init_rn – Initial single-read read noise (DN), a float or a 2D array of shape (Nrows, Ncols). Fixed if fit_rn is False.

  • input_dq_raw – 4D array of shape (Nfiles, Nreads, Nrows, Ncols) of per-read DQ flags. Default is None.

  • dq_flags – Dict mapping DQ flag names to bit values, with keys DO_NOT_USE, SATURATED and JUMP_DET. If input_dq_raw or dq_flags is None, all read differences are used. Default is None.

  • fit_gain – If True, fit the gain. Default is True.

  • fit_rn – If True, fit the read noise. Default is True.

  • method – "quad" fits a quadratic form to the log likelihood on a 3-point grid around the initial values, then again around the first result. "grid" evaluates the likelihood on a dense grid and takes the errors from the marginal posteriors. "both" runs the grid search, then the quadratic fit around its peak. Default is "quad".

  • delta_gains – 1D array of gain offsets (e-/DN) from init_gain to evaluate. Must have 3 elements [-d, 0, d] for "quad" and more than 3 for "grid" and "both". Default is [-0.2, 0, 0.2] for "quad" and np.linspace(-1, 1, 51) otherwise.

  • delta_rns – 1D array of read noise offsets (DN) from init_rn, as for delta_gains. Default is [-0.5, 0, 0.5] for "quad" and np.linspace(-10, 10, 51) otherwise.

  • countratesidentical – If True, assume every ramp of a pixel has the same count rate. Default is False.

  • mode – "per_pixel" fits each pixel; "full_detector" fits one gain and read noise to all pixels at once. Default is "per_pixel".

  • max_cores – Number of processes for "per_pixel". Default is 1.

Returns:

  • gain (np.ndarray or float) – Best-fit gain (e-/DN), 2D float32 array of shape (Nrows, Ncols) for "per_pixel", else a float.

  • rn (np.ndarray or float) – Best-fit read noise (DN), same shape as gain.

  • cov (np.ndarray) – Covariance of (gain, rn), 4D array of shape (2, 2, Nrows, Ncols) for "per_pixel", else 2D of shape (2, 2). Entries of a fixed parameter are NaN, as are the off-diagonal terms unless both are fit with "quad" or "both". With "grid", the diagonal holds the errors rather than the variances, and rn is NaN unless it is fit.

References

Brandt, T. D. (2025), “Computing the Electronic Gain for Detectors Read Out Up-the-ramp”, PASP, 137, 125006.
